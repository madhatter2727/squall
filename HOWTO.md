# Squall — how to use
1. Open https://squall-sky.vercel.app on your phone (Add to Home Screen for the full-screen look).
2. Home is Apopka. Tap the place name → search and save another town, or Use my location.
3. Scrub the 24-hour strip for rain/heat; tap a Dry window preset (Walk, Errands, Mow, Laundry, Grill) to see when outside works.
4. Radar plays the latest loop; Tropics shows Atlantic quiet or any active storm (plus Pacific ones like Trudy); Alerts only shout when NWS has one.
5. Pull down to refresh. Offline keeps the last good snapshot with its time stamp. No background pinging.
